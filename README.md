# linux-t2-ncz

Complete corresponding source for the NCZ-OS amd64 kernel
**`7.3.0-rc7-t2-ncz`, Debian package version `7.3.0-rc7-2`**, as shipped in
NCZ-OS 26.10 Preview 1 (`linux-image-7.3.0-rc7-t2-ncz_7.3.0-rc7-2_amd64.deb`
and its `linux-headers` / `linux-libc-dev` companions).

The kernel is mainline Linux plus the patch series in `patches/`, configured
with the configuration in `config/`, built and packaged by `build.sh`.
Nothing else goes into the binary.

## What it is built from

| Part | Value |
|---|---|
| Upstream base | Linux `v7.3-rc7`, commit `24a19b953e2a3d0ea5a8c4951a0ab8f32720c907` (annotated tag object `ec8bf8280261294a9b9b4520414b42704c7f9f6b`) in <https://git.kernel.org/pub/scm/linux/kernel/git/torvalds/linux.git> |
| Patch series | `patches/` — 24 patches, applied in file-name order (listed in `patches/series`) with `patch -p1` |
| Configuration | `templates/default-config-debian` + the `scripts/config` edits in `build.sh`, resolved by `make olddefconfig`. The resolved result is `config/kernel_config_7.3.0-rc7-t2-ncz` (sha256 `e88c4505d5c4a9fce3720eb0ba2892aede33f12080865cb45bfbee2acc09219a`, identical to `/boot/config-7.3.0-rc7-t2-ncz` in the shipped package) |
| Build and packaging | `build.sh` (`make deb-pkg LOCALVERSION=-t2-ncz KDEB_PKGVERSION=7.3.0-rc7-2`) |
| Build environment | Debian 13 "trixie" container (`debian:trixie`), gcc 14.2.0-19 |
| Shipped build record | `config/PROVENANCE-7.3.0-rc7-t2-ncz.shipped` (base commit and the sha256 of every patch file the build applied) |
| Shipped binaries | `SHIPPED-ARTIFACTS.sha256` |

The patch series comes from the [t2linux](https://t2linux.org) project
(T2 BCE/VHCI/audio, Touch Bar, trackpad, APFS, Broadcom Wi-Fi/Bluetooth
quirks) plus local fixes (`2010`, `9001` local change, `9011`, `9013`,
`9101`, `9102`, `9503`, `9504`). Each patch carries its own author and
description.

One patch file differs from the build record only in its description text:
the commit message of `9011-PCI-AER-skip-ANFE-unmask-on-Apple-T2-SEP.patch`
was reworded (sha256 at build time
`f3c98cb1a151d42d1a02cec6e533f67d09ce4839efbc67b59bb607c006819cc4`). Its
code hunks are unchanged: applying this series and the build-time series to
the base gives the same source tree (git tree
`451b5dfee3eb77e15dac561766000bc3ec2e4f41`, as recorded by `git add -A`).
All 7553 source files in the shipped `linux-headers` package that also exist
in this tree are byte-identical to it; its other 66 files are generated by
the build.

## Rebuild

On a Debian trixie system or container, as root, from a checkout of this
repository, with about 30 GB free under the work and artifact directories:

```sh
T2_WORKING_PATH=/srv/work T2_ARTIFACTS_DIR=/srv/artifacts ./build.sh
```

`build.sh` installs its build dependencies with apt, clones tag `v7.3-rc7`
from kernel.org (GitHub mirror as fallback), applies `patches/`, writes the
configuration, checks it, and runs `make deb-pkg`. The defaults
(`KERNEL_VERSION=7.3-rc7`, `PKGREL=2`, `T2_LOCALVERSION=-t2-ncz`) reproduce
this release. See the comment block at the top of `build.sh` for every knob.

The `.deb` files will not be bit-identical to the shipped ones (timestamps
and build paths are embedded), but the source tree and the configuration
are.

## Check this source against the shipped kernel

```sh
./verify.sh /path/to/linux    # a linux.git clone that has tag v7.3-rc7
```

`verify.sh` checks the patch hashes against the build record, applies the
series to `v7.3-rc7` in a scratch directory, and prints the resulting git
tree id (expected `451b5dfee3eb77e15dac561766000bc3ec2e4f41`). To compare
the configuration, extract `/boot/config-7.3.0-rc7-t2-ncz` from the shipped
`linux-image` package and compare it with `config/kernel_config_7.3.0-rc7-t2-ncz`.

## Out-of-tree modules

The NCZ-OS amd64 image also ships DKMS modules (t2smc, t2gmux, t2smp,
t2thunderbolt) that are built on the installed system. Their source is in
the NCZ-OS installer repository,
<https://gitlab.com/ncz-os/cix-installer>, under `assets/kernel/`.
